## Micro SD Card (experimentel)
- Added support for SD cards, including both Phoenix Contact licensed and non-licensed third-party SD cards.
- Recommended characteristics for maximum lifetime and reliability:
  - Industrial or High Endurance grade
  - Memory type: pSLC or SLC
  - Temperature range up to +85 °C
  - UHS-I U3
  - Video speed class V30 or better (~30 MB/s)
  - Application performance class A1 or A2
  - microSDXC up to 2 TB
- Use a high-quality storage card to ensure maximum service life.

## USB Interface
- Added support for various gateways via the USB interface (e.g. M-Bus, wM-Bus, EnOcean).
- Only serial interfaces are supported that are exposed as `ttyUSB(x)` or `ttyACM(x)`.
- USB devices are mounted under `/dev/usb-devices` and can be used directly inside OCI containers.

## WBM
- New WBM configuration site for KNX 
- The integrated KNX IP router can optionally be bound to the second network adapter (LAN3).
- The Wibu license container is now created automatically if it does not exist. Previously, it had to be created manually via the WBM.
- The time and date can only be set via NTP. For this reason, NTP is enabled by default upon delivery and is preset to `pool.ntp.org`.
- Upon delivery, the DNS server is preconfigured by default with the entries “8.8.4.4” and “8.8.8.8”
